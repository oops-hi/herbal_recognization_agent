## 四、古籍引文来源与口径（2026-08-30 落地）

- **载体**：《神农本草经》通行本（12 味，含 枸杞/杏核/桃核/山茱萸/连翘/支子/地肤子/五味/练实/栝楼/梅实/蓬蔂 条目）+《本草纲目》（8 味：缩砂密/白豆蔻/豆蔻/补骨脂/茴香/木瓜/山楂/金樱子 条目）
- **抓取来源**：zh.wikisource.org 电子文本（MediaWiki action=parse API 抓 wikitext），`source_edition` 如实标注「维基文库《神农本草经》通行本（三卷）电子文本，逐字照录（括注为整理本所加）」/「维基文库《本草纲目》电子文本（明刊本系），逐字照录（各家注文原样保留）」
- **繁体保留**：quote 逐字照录原文（含繁体、异体如「欬逆」「練實」「蓬蔂」），不简化——忠实于所据文本；解读用简体
- **首载争议处理**：5 味起草稿书名有疑（砂仁/木瓜/小茴香/补骨脂/金樱子），统一以《本草纲目》成书条目为引文载体，首载争议留给 quote_loc 中纲目自引的注文呈现（如《开宝》《蜀本》《别录》），不在 source 字段断言首载书
- **纲目「豆蔻」条说明**：纲目「豆蔻」条含草豆蔻、草果诸品（引《本经》即古豆蔻条），用于草豆蔻；白豆蔻为独立条目，用于豆蔻——quote_loc 已分别注明
- **教学亮点（口径差异已写入解读）**：木瓜纲目言"寒"→ 药典"温"；山楂纲目言"冷"、时珍"微温" → 药典"微温"；枸杞本经"味苦寒" → 药典"甘，平"；杏核本经"味甘温" → 药典"苦，微温"。解读统一收尾「本条仅作学术参考，以药典口径为准」
