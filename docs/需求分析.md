## 1. 项目背景

### 1.1 政策与行业趋势

中医药数字化、智能化已进入国家政策议程，且正在从"政策表述"走向"具体工程量"：

| 依据 | 相关表述 |
|---|---|
| 《中华人民共和国中医药法》（2017 施行） | 鼓励中医药科学技术创新；要求建立中医药传统知识保护数据库 —— 数字化的法律基础【[来源](https://www.nhc.gov.cn/fzs/c100048/201808/fcdec86bf0ea43fd889ef945a3d0e181.shtml)】 |
| 《"十四五"中医药发展规划》（国办发〔2022〕5 号） | "加快中药制造业数字化、网络化、智能化建设"；推进饮片信息化追溯体系；**鼓励中药智能辅助诊疗系统研发应用**【[来源](https://www.beijing.gov.cn/zhengce/zhengcefagui/202203/t20220329_2642656.html)】 |
| 《"十四五"中医药信息化发展规划》（2022-12） | 明确智慧中医医院、中医智能辅助诊疗系统、**智慧中药房**、中医药数据资源治理等任务【[来源](https://www.gov.cn/zhengce/zhengceku/2022-12/06/content_5730292.htm)】 |
| 五部门《促进和规范"人工智能+医疗卫生"应用发展的实施意见》（国卫办规划发〔2025〕30 号） | 确立 **"人工智能赋能而不替代"** 定位，分级分类监管【[来源](https://www.gov.cn/zhengce/zhengceku/202511/content_7047018.htm)】 |

行业规模（多机构口径差异，引用须注明机构）：

- 中药饮片市场约 **3038 亿元**（2024，+8.97%）；中药材市场成交额约 **2110 亿元**（中商产业研究院）【[来源](https://www.askci.com/news/chanye/20250425/090445274554308567748427_3.shtml)】
- 药食同源市场 **3700 亿元**（2025，+21.6%）——"自己买药材泡水/煲汤"的群体规模庞大【[来源](https://news.ycwb.com/ikinvjitkc/content_53840645.htm)】

### 1.2 需求真实性：三组硬证据

**证据一：饮片外观形态是质量问题的第一大来源。**
《国家药品抽检年报（2024）》：中药饮片专项抽检 10 个品种 2192 批次，63 批次不符合规定（不合格率约 2.87%）；其中 **"性状"不合格占 57.5%**（42/73 项次）。性状即外观形态——**这正是图像识别技术可以干预的环节**【[来源](https://www.chinanews.com.cn/gn/2025/03-27/10389751.shtml)】。

**证据二：外形相似药材误配是真实致死事故。**
- 2007 年大连机车医院将大毒药「天仙子」当作「**地肤子**」配出，患者中毒后不足 5 个月死亡【[来源](https://news.cctv.com/society/20071203/103420.shtml)】
- 2008 年云南会泽医院将「藜芦」当作「茯神」调配，致 3 人死亡【[来源](http://news.cctv.com/china/20080324/106292_1.shtml)】
- 香港 6 年 62 起乌头碱中毒个案中，**21 起属"隐性中毒"——处方并无乌头类药，是抓错药所致**【[来源](http://www.hkjtcm.org/journals/2010%E5%B9%B4%E7%AC%AC%E4%BA%94%E5%8D%B7%E7%AC%AC%E5%9B%9B%E6%9C%9F/19.%20%E5%BE%9E%E9%A6%99%E6%B8%AF%E4%B8%AD%E8%97%A5%E4%B8%AD%E6%AF%92%E4%BA%8B%E4%BB%B6%E6%89%80%E6%83%B3%E5%88%B0%E7%9A%84.pdf)）

> ⚠️ **边界声明**：本系统 20 类类别表**不含**「天仙子」「藜芦」等混伪品种。上述案例只用来说明"外形相似药材辨识"需求真实存在，**不代表本系统能防住该事故**——覆盖混伪品是后续版本（V2）扩展方向。答辩被追问时如实回答即可，切勿夸大。

**证据三：自我用药的高风险场景普遍存在。**
- 2023 年女大学生误把**商陆**（大毒）当人参咬食，昏睡 17 小时【[来源](https://m.thepaper.cn/newsDetail_forward_25575824)】
- 2026 年央视《财经调查》：**生附子**（含乌头碱）被包装成"养生茶"网售，销量链接超 6 万单，上海 35 岁男子网购熬煮后死亡【[来源](https://www.ctdsb.net/c1716_202607/2814809.html)】
- 网售"酸枣仁"出现**扁豆染色冒充**案（正品约 800 元/斤，假货 20 元，单一链接销量 30 万件+）；最高检 2025 年 11 月发布相关典型案（水红花子冒充酸枣仁、桔梗片冒充人参，涉案 274 万元，最高获刑十六年）【[来源](https://news.jcrb.com/jsxw/2025/202511/t20251105_7205773.html)】

### 1.3 技术现状：两头强，中间断

- **图像识别**：中药材识别论文准确率普遍 90%+。对标本项目的最近工作为 MSPyraNet（*Applied Sciences* 2025），同样 **20 类 4485 张** 规模数据集 CHMD2 上取得 **89.22%**【[来源](https://www.mdpi.com/2076-3417/15/8/4271)】；163 种 27.7 万张图上 EfficientNet-B0 达 99.0%（*中国全科医学* 2025）【[来源](https://www.chinagp.net/fileup/1007-9572/PDF/2024-070414.pdf)】
- **知识条件**：中医药知识图谱平台成熟且开放——TCMKD（成都中医药大学，约 14.4 万实体、360 万关联，2025 年发表于 *Journal of Pharmaceutical Analysis*）【[来源](https://www.cdutcm.edu.cn/info/1075/134741.htm)】、TCM-MKG（中国药科大学）、OpenKG SCG 等。
- **LLM+图谱融合问答**已被证明可显著降幻觉：医学问答系统（Frontiers in Medicine 2024）忠实度评估 0.9375【[来源](https://www.frontiersin.org/journals/medicine/articles/10.3389/fmed.2024.1512329/full)】

**结论：识别能力与知识能力分别在学术界已就绪，但在"一个可用的产品"里两者尚未打通。这正是本项目的切入点。**

### 2.3 空白点结论

1. **识别与知识的断层**：市面上要么"**只识别不解释**"（通用植物 App、多数小作坊产品），要么"**只有知识没有视觉入口**"（百科类 App、图谱平台）。
2. **无产品把"识别 → 药性 → 禁忌 → 溯源"串成一条链路**：专业系统（照药镜）做到识别+药性，但止步于此；学术系统把图谱或识别做到极致，但不是面向用户的产品。
3. **教学刚需与工具供给错位**：中药鉴定实训要求学生"200 种以上饮片限时识别"（课程终结性评价占 50%），实物标本却"无法人手一个"、教材配图为黑白印画；现有工具是 3D 仿真而非真实拍照。
4. **安全提示责任缺位**：几乎所有消费级产品只以一句免责声明回避禁忌问题，唯一给出"十八反十九畏预警"的是院内私有系统。

## 3. 目标用户与场景

### 3.1 用户画像（Persona）

**P1 · 中药学专业学生（核心用户）**
- 背景：本科生，修读《中药鉴定学》《中药学》，需"见药知名"并背诵约 200 味常用饮片的性味归经、功能主治【[来源](https://www.nhic.edu.cn/system/resource/pdfjs/viewer.html?file=%2F__local%2F8%2F66%2F40%2F62641D2BE0E64BA52F91379F500_ABA14EAF_84EA3.pdf)】
- 场景：实验课前预习（拿药房饮片照片核对性状）、课后复习（对着抽屉里的药材自查）、实训考核前突击
- 痛点：背了就忘、标本不够看、教材图片与实物差距大
- 价值：**识别 + 即时讲解 = 随身标本馆；多轮问 = 随问随答的"口袋老师"**

**P2 · 基层药房调剂员/店员（技术型用户）**
- 背景：转岗或初入行的从药人员。国家职业标准要求初级识别约 120 种、中级 200 种、高级 300 种饮片，且"十八反十九畏配伍禁忌、毒性饮片使用要求"属基础知识【[来源](https://www.osta.org.cn/api/sys/downloadFile/decrypt?fileName=4eNsZIOv3WFNDfbnldJHeA/2024/4/29/db0ebc3517cb42c3af30838c23b9f1c4.pdf)】
- 场景：饮片入库验收时对可疑饮片拍照初查；面对顾客"这药和那药能一起吃吗"式咨询时快速查证
- 痛点：相似饮片难辨（天仙子/地肤子案即是职业场景）、配伍禁忌靠背
- 价值：**识别 + 禁忌知识提示 = 防错助手**（定位为参考工具，不构成验收结论）

**P3 · 养生人群/患者家属（轻用户）**
- 背景：中年以上健康焦虑人群 + 紧跟"养生趋势"的年轻人；药食同源消费中 18–35 岁占比达 80%【[来源](https://www.21jingji.com/article/20260227/herald/af11b94ffce0d0e727661dbf0ee4cfb4.html)】
- 场景：网购药材到手拍照自检、泡水/煲汤前确认品种、看短视频偏方配药前求证
- 痛点：真假难辨（染色酸枣仁、硫熏当归、洋姜冒充九制黄精）、误认误食（商陆当人参/野菜）、煎煮方法认知差（"先煎后下"不知道者占 46.9%【[来源](https://www.scholarmate.com/S/TyPECr)】）
- 价值：**识别 + 安全提示 + 溯源科普**；必须配强免责声明

### 3.2 用户旅程（示例，P1 核心路径）

```
预习《中药鉴定学》"果实种子类饮片"单元
  → 打开系统拍照上传一颗家里买的炮制饮片（实际为桃仁）
  → 系统返回 Top-3：桃仁 0.93 → 苦杏仁 0.04 → 乌梅 0.02，低风险
  → 追问"桃仁和苦杏仁怎么区分？"
  → 智能体自动调用两次图谱查询，对比两药性状特征与性味归经，回答带出处
  → 追问"为什么老师说桃仁孕妇要慎用？"
  → 智能体检索图谱"妊娠禁忌"边，说明慎用依据（活血，动血之力较强），并作知识展示声明
  → 用户收起对话，查看可展开的"工具调用记录"了解推理过程
```

## 4. 产品定位与目标

### 4.1 产品定位（一句话）

> **中药饮片智能辨识与用药安全知识助手**：拍一张饮片照片，用自然语言追问药性、配伍禁忌与经典方剂，每条结论都可溯源到知识图谱节点与典籍出处。

**产品形态**：Web 应用；分类模型本机推理（自训练 CNN），大模型为 DeepSeek `deepseek-chat` 云端 API（文本）；知识图谱本机存储（NetworkX + JSON），无外部服务依赖。

### 4.2 差异化（5 条）

| # | 差异点 | 说明 |
|---|---|---|
| 1 | **识饮片而非鲜活植物** | 与形色/百度识图错位竞争：面向药房抽屉里的干燥饮片——学生实训与药房验收的真实形态 |
| 2 | 识别之后接**结构化知识图谱** | 答案不是大模型自由发挥的百科，而是来自可审计的 JSON 图谱 |
| 3 | **配伍安全主动提示** | 十八反十九畏/毒性分级/妊娠禁忌，用户没问也要提示；且**歌诀与药典两套依据并存、差异处如实说明** |
| 4 | **结论可溯源** | 每条药性标注图谱来源节点 + 典籍出处；图谱没有就明说"知识库未收录" |
| 5 | **智能体多轮编排** | "查词典"升级为"问顾问"：一句复合问题自动拆成多次图谱查询（见 6.2） |

### 4.3 明确不做（范围边界）

| 不做 | 原因 |
|---|---|
| 输出诊断结论、辨证分型、**针对具体用户的剂量/用药建议**、疗效预测 | **合规红线**：此类输出按"辅助决策类"软件管理（第三类医疗器械，需临床试验）。药典用量只在"药材档案"中作知识条目展示，绝不表述为"你应该用 X 克" |
| 鲜活植物／中成药成品识别 | 数据集不支持，且已有成熟竞品 |
| 真伪掺假、硫熏、染色鉴别 | 需理化检测，图像分类原理上做不到 |
| 混伪品识别（如水红花子冒充酸枣仁） | 本版 20 类不含混伪品数据；V2 扩展方向 |
| 产地溯源、价格行情 | 与核心价值无关 |
| 覆盖药典全部药材 | 本版仅 20 味果实种子类，扩展性在架构上留口 |

### 4.4 成功指标（课程项目以可复现质量指标为准）

| 指标 | 目标 | 测量方式 |
|---|---|---|
| 同域识别准确率（验证集） | ≥ 90%（对标公开基准：20 类 CHMD2 上 89.22%） | `evaluate.py` |
| **跨域识别准确率**（药房实拍集，训练用网络图） | ≥ 70%。**低于同域是预期现象**，作为报告分析章节而非失败 | `evaluate.py` |

| **结论溯源率** | 100%——每条药性/方剂结论均标注图谱来源 | 20 条测试问答人工核查 |
| **安全提示召回率** | 涉及毒性/妊娠/十八反的问题 100% 主动提示 | 10 条专项测试问题 |
| 多轮工具调用成功率 | ≥ 90% | 20 条复合问题，看 trace 是否走完整 |
| 单轮响应时延 | 识别 < 1s；智能体回答 < 15s | 本机计时 |

## 6. 核心流程设计

### 6.1 主流程（第一次使用）

```
用户上传图片 → 格式/大小/完整性校验 → CNN 推理 → Top-3 + 置信度
→ Top-1 ≥ 0.6 ? ──是──→ 识别卡：中文名、置信度、图谱档案摘要、安全提示
                 └─否──→ 拒答：提示"可能非药材或拍摄条件不佳"，给补拍建议
用户自然语言提问 → 智能体循环（≤8 轮，工具调用链回传前端实时展示）
→ 最终回答 → 前端附加免责声明
```

### 6.2 智能体能力（产品语言）

用户问「**这个能和菊花一起泡水吗？我最近眼睛干**」（已识别为枸杞子），智能体可能自主执行：

```
① recognize_herb()          → 确认待查药材（枸杞子）
② get_herb_profile(枸杞子)   → 甘·平，归肝肾经，滋补肝肾、益精明目
③ get_herb_profile(菊花)     → 甘苦·微寒，归肺肝经，疏散风热、平肝明目
④ check_compatibility([枸杞子,菊花]) → 无十八反十九畏冲突（知识展示）
⑤ find_formulas(症状=肝肾阴虚目昏) → 杞菊地黄丸（枸杞子佐、山茱萸臣…）
⑥ 汇总：两者无冲突；枸杞子补、菊花清，经典组合；给出方剂示例与出处
```

**关键点：调用顺序与次数由问题决定，不由代码决定**——这是"智能体"与"固定流水线"的根本区别（第 5 条差异化）。

### 6.3 异常与降级

| 场景 | 产品行为 |
|---|---|
| 置信度 < 0.6 | 不下结论，展示 Top-3 供人工判断 + 补拍指引（干燥饮片特写、光照均匀、纯色背景） |
| 图谱未收录该信息 | 明说"知识库未收录"，**禁止模型凭记忆补** |
| DeepSeek 限流（429） | 单次退避重试；仍失败则提示稍后再试，识别结果保留 |
| 余额不足（402） | 不重试，直接提示配置问题 |
| 完全断网 | 识别与图谱页正常，对话区提示"当前离线，仅知识库查询可用" |
| 工具执行异常 | 错误信息回填给模型，由模型改写为用户可懂的说明 |

| 方剂组成与君臣佐使 | 依教材整理 | 以《方剂学》教材核对 |

| 院校标本缺口数量 | 无全国统计 | 用定性证据（"实物标本无法人手一个"），不写具体数 |

## 10. 验收标准

### 10.1 量化验收（对应 4.4）

1. `evaluate.py` 输出 val/test 双份 accuracy + per-class F1 + 混淆矩阵 PNG
2. 20 条测试问答逐条核查"溯源率 100%"
3. 10 条安全专项问题核查"提示召回率 100%"
4. 20 条复合问题核查"工具调用成功率 ≥ 90%"

### 10.2 功能用例（演示脚本 = 验收用例）

| # | 步骤 | 预期 | 属性 |
|---|---|---|---|
| 1 | 传一张药房实拍枸杞子 | Top-1 枸杞子，置信度展示，档案摘要 + 图谱出处 | P0 |
| 2 | 问"这个能和菊花一起泡水吗？我最近眼睛干" | 智能体 5~6 次工具调用（识别/双档案/禁忌/方剂），回答带溯源 + 杞菊地黄丸示例 | P0 ★必演 |
| 3 | 追问"那它用量多少" | **指代消解**，不重传图片；以知识条目展示用量，非"你应该用 X 克" | P0 |
| 4 | 问"瓜蒌皮能和川乌一起用吗" | 主动提示十八反，标注歌诀来源 + 药典认定 | P0 ★必演 |
| 5 | 传一张宠物照片 | 拒绝下结论 + 补拍建议 | P0 ★必演 |
| 6 | 拔网线 | 识别与图谱页仍可用；对话区友好降级提示 | P0 ★必演 |
| 7 | 打开图谱可视化页 | 离线渲染，无 CDN 依赖 | P1 |

★必演项 = 最体现"非玩具"定位的三个动作：禁忌双源、拒答、断电。
